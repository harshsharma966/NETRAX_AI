# Model Weights Directory

Place your pre-trained model weights in their respective directories:

- **Person Detection**:
  - Path: `models/person_detection/yolo11n.pt`
  - YOLO11 Nano weights for human detection (auto-downloadable via Ultralytics).

- **Face Detection**:
  - Path: `models/face_detection/face_detector_weights.pth`
  - Face detector weights (e.g., RetinaFace / MTCNN / YuNet).

- **Face Recognition**:
  - Path: `models/face_recognition/best_model.pth`
  - Feature embedding backbone (e.g., ArcFace / MobileFaceNet / AdaFace).
